### 二、核心优化方向（按COC跑团全流程+特色机制划分）
#### 1. 团前准备（主持侧为主）
- 剧本/模组管理
  - 模组库（标签体系：年代/地点/人数/时长/难度/主题雷点）
  - 章节/场景拆分（Scene：地点、出场NPC、可用线索、触发事件）
  - 关键结局/分支树（流程图/节点条件）
- NPC管理
  - NPC卡（属性、关键话术、动机、秘密、关系）
  - NPC与线索/地点关联
- 玩家招募与排期
  - 场次（Session）安排：时间、时长、语音平台、报名/候补
  - 团前问卷（边界/雷点、玩法偏好、可接受恐怖程度）

#### 2. 开团房间（Session进行中）
- COC掷骰与检定系统（核心）
  - 支持COC7常用规则：奖励/惩罚骰、困难/极难检定、对抗检定
  - 暗骰/私聊骰（仅主持可见）+ 公开/半公开模式
  - 骰子宏（如#侦查 70、#图书馆 60 困难、#SC 1/1d6）
  - 自动生成检定记录（成功等级、大成功/大失败判定）
- 行动与轮次（偏战斗/追逐）
  - 先攻/行动顺序、回合记录
  - 追逐规则辅助（段落记录、障碍/距离）
- 房间状态面板（主持控制台）
  - 一键投放：图片/手册页/地图（可设置玩家可见/不可见）
  - 快捷触发事件：念白模板、音效/BGM、系统提示

#### 3. 角色与人物状态（COC特色强化）
- 角色卡增强
  - 技能快速检定入口（点击技能即掷骰）
  - 装备/资产/现金流水（适配COC常用需求）
  - 背景与关系（与NPC/玩家的关系线）
- 理智（SAN）与疯狂系统（COC标志性）
  - 理智检定（SC）：自动扣SAN、记录原因/来源
  - 临时/不定期/永久疯狂判定与持续时间
  - 恐惧症/躁狂症/精神分析治疗记录
- 伤害与濒死/治疗
  - HP变化、重伤标记、急救/医学检定记录
  - 长期治疗/休整日志

#### 4. 调查与线索管理（COC核心）
- 线索结构化
  - 线索类型：物证/证词/文件/地点/谜题/传闻
  - 线索字段：来源场景、可靠性、是否误导、可共享范围
  - 线索图片/附件管理（延续现有图片存储迁移优化）
- 线索墙/关系图（强推荐）
  - 节点：NPC/地点/物品/事件/组织
  - 边：关系类型（目击/所属/交易/仇恨/亲属/时间先后）
  - 主持可设置“玩家已知/未知”，逐步解锁
- 时间线
  - 自动从日志/线索生成时间线（案发前后事件顺序）

#### 5. 日志、战报与复盘
- 结构化团内日志
  - 自动归档：掷骰、SC、SAN变化、关键线索获取、主持投放内容
  - 区分“主持私密注记”与“玩家可见战报”
- Session总结
  - 每次Session结束自动生成战报（支持手动编辑）
  - 进度点记录：已触发场景、未解决悬念、下次待办

#### 6. 玩家协作与社交
- 玩家笔记协作
  - 共享笔记/私密笔记、引用线索（@线索、@NPC）
  - 笔记版本/回滚（避免误删）
- 团队工具
  - 投票/表决（调查方向、剧情选择等）
  - 安全工具：X卡/O卡/暂停按钮（适配COC恐怖/边界需求）

#### 7. 权限与反作弊（全栈层面）
- 细粒度权限
  - 主持：全可见、暗骰、私密线索、场景编辑
  - 玩家：仅可见授权内容、不可查看暗骰/主持注记
- 数据一致性
  - 客户端仅负责显示，关键规则结算（SAN扣减、暗骰结果）由后端/数据库保障
- 内容审计
  - 关键改动（线索可见性、SAN变更、内容删除）写入审计日志，便于复盘/纠纷处理

#### 8. AI特色辅助（差异化卖点）
- AI辅助主持
  - NPC即兴对话建议、场景氛围描写模板
  - 基于“已知线索墙”生成下一步调查方向（不剧透未解锁内容）
- AI战报整理
  - 从房间日志生成可读战报，标注关键线索与SAN变化

---

### 总结
1. 现有模块已覆盖COC跑团的**基础框架**（房间、角色、线索、聊天等），优化方向聚焦于“COC特色机制”和“全流程体验”；
2. 优化核心围绕**三大维度**：主持侧效率（团前/团中工具）、玩家侧体验（协作/角色状态）、系统侧保障（权限/数据/审计）；
3. AI辅助是差异化卖点，需贴合COC跑团逻辑（不剧透、强化氛围/战报），而非单纯的通用AI功能。
